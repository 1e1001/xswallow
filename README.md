# `xextra`
Variety of utilities for X-windowing.

__/!\\__ this project isn't entirely complete, but is functional enough to use. I'm kinda bored with xcb's lack of documentation on anything so if y'all wanna fix this feel free.

## Features
- [Window swallowing](./doc/swallow.md)
- [Audio bell](./doc/bell.md)

Also see [Configuration](./doc/config.md).

## Installation
Not on crates.io, `cargo install` with `--git` or `--path`
